# Dataset and model provenance

This inventory records external datasets and pretrained models referenced by the current code. It was checked on 2026-10-05. Dataset/model terms can change; read the linked source terms before downloading, using, or redistributing an artifact. A Hugging Face mirror's license metadata does not necessarily grant rights to underlying images or other third-party material.

This is a source inventory, not a legal opinion. No raw dataset files or model weights are stored in this repository's tracked tree. On 2026-10-04, the 54 PNG experiment artifacts and the remaining non-Markdown raw run artifacts formerly tracked under `docs/experiment_data/` were removed; only aggregate Markdown reports remain there. Training outputs, generated images, checkpoints, and downloaded caches may contain or derive from third-party material and must be reviewed separately before publication.

## Third-party Python dependencies

`requirements.txt` and `requirements-dev.txt` name third-party packages but intentionally do not pin versions. A file-type scan of the tracked tree found no non-text files, such as vendored wheels, shared libraries, model weights, or image/dataset artifacts. Installing these requirements obtains third-party software separately; the repository's MIT OR Apache-2.0 license does not replace those packages' own licenses. This source inventory does not certify the license of every version that a resolver may select. For a redistributed environment, container, or package, record the resolved versions and generate a version-specific license/SBOM report before distribution.
